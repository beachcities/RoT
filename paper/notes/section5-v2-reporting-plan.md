# 第5節への計器v2還元——執筆方針の事前登録

2026-08-27朝、本測定（n=400）の走行前に山田決裁で固定。**結果を見る前に、再現した場合としなかった場合の両方の書き方を同じ場所に定める**。計器側の規則は第二凍結（`instrument-v2-freeze2.md`）、本文書は稿側の執筆規則。

## 1. 時系列の保持

稿でも pilot（規則制定に使ったデータ）→ 第二凍結 → confirmatory（n=400）の時系列を保持する。「pilotで見えたもの」と「confirmatoryで再現したもの」を混ぜない。推定値にpilotをpoolしない（凍結第3節）。

## 2. 両出口の固定

- 本測定で同じ形（γ超えの不在、棄権のt応答、H=1三経路の割れ）が出た場合：「再現した」と書く。
- 出なかった場合：それ自体を結果として、**同じ場所に**「pilotで観測された構造は独立反復では安定しなかった」と書く。隔離しない、軽くしない、書かないという選択肢を持たない。

## 3. v3/v4対照の表現上限

因果語（「再試行が正答を作っていた」等）は使わない。上限は：**再試行を許す成功率と、一発応答の分布集中は異なる量であることを可視化した**。意義の書き方はこちらを主に：能力の有無という二値から、**一発でどの程度安定してその能力へ到達するかを分離した**。

## 4. H=1三経路

観測の記述まで。届き方の形への帰属は書かない（識別には文書長・内容を揃えた別設計が要る。次段へ）。
