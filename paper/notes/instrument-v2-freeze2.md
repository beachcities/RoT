# 計器v2 第二凍結——fit判定・読み取り・本測定n・除外規則

2026-08-27未明、chat起草・外部レビュー反映・山田決裁。仕様v2.0第8節⑦の定める、パイロット後・本測定前の凍結点。**本文書の規則はパイロット（run 20260826T132218Z）の観測を見た後に制定した事後規則であり、本測定へは事前規則として適用する**——制定の時系列を隠さないことを凍結制度の要件とする。

**γの二役の分離**：γ=1/Hは無情報の当て推量の正答率（chance baseline）という**定義量**。「γ±0.05」は格子表示と判定に使う**運用閾値**であり、統計的検定ではない。両者を文中で混用しない。

## 1. fit判定（二段）

断面（t=0、t=1を各々独立に）について：

- **fitを実行する条件**：正解山占有率がγ+0.05を超える点が2点以上あること。
- **fitを採用する条件**：**情報増加方向（xの減少方向）に増加する4パラメータロジスティック**として適合すること（増加の向きは制約として固定——減少曲線の「成立」を排除する。下限・上限は自由推定＝下限をγに固定しない。m=中点、w=10–90%幅、最小二乗）。生値5点の単調性は実行条件に**しない**——有限標本の揺れによる1点の逆転でfitを禁止しないため。単調性・残差は**fit後の適合性診断として報告**する。

いずれかの段で満たされない断面は**「当てはめ不成立」を正式な結果として記録する**——不成立は失敗ではなく、正答側が秩序変数として立たないという知見。パイロットでは両断面とも実行条件を満たさない（t=0: 0, 0, 0, 0.20, 0.22／t=1: 0.25, 0.09, 0.12, 0.08, 0.00）。

## 2. 主要読み取り量（co-primary、並列）

- **正解山占有率（γとの関係を含む）と棄権率**を、並列の主要読み取り量とする。主／従は設けない。
- 経緯の明記：元設計は正解山占有率を中心に置いていた。棄権率はパイロットで発見された構造（t=2で0、重い側0.19〜0.58とtに応答）であり、その発見を受けて本凍結で並列の主要量へ加えた——この選択の時系列を隠さない。
- 従属量：山の数・最大山占有率・エントロピー、総トークン、変種内／変種間の揺れ。
- H=1三経路（直接記載／t=0消去確定／t=1消去確定）は**記述的比較のみ**。パイロットの観測は「三経路で占有率が割れた」（1.00／0.22／0.00）まで。届き方の形への**帰属は行わない**——識別には文書長・内容を揃えた対の別設計が要り、本測定の範囲外として次段へ積む。

## 3. 本測定のn

- **本測定 n=400**＝パイロットと同一の200標本設計を、別のmaster seed帯で**2回反復**（推定2×8時間、課金$0）。
- **パイロットのn=200は本測定の推定値にpoolしない**。パイロットは判定規則の制定に使ったデータであり、最終推定に混ぜると規則と推定の独立が崩れる。再現性評価の**外部参照としてのみ併記**する（pilot 200 / confirmatory 400 の区分を固定）。
- 効果量からのn逆算を採らない理由：パイロットで正答側の効果が極端（0対1.00）で逆算が意味を持たない一方、セル推定値の**反復間の振れ**こそが本測定の主目的（BIRDで出る差の物差し）だから。反復2本＋外部参照のパイロットで、セル別推定値の再現性を直接測る。

## 4. 除外規則と一発勝負の閉じ

- 区間が標本0で落ちた場合（パイロット区間1と同型）：その区間を破棄し、未取得の標本のみ次区間で走行する。
- **チェックポイント済みの標本は保持し、同一標本を再実行して置換しない**（一発勝負原則の帰結。いかなる理由でも、取得済み標本の値の差し替えを禁ずる。破棄が必要な事態が生じた場合は標本単位でなくラン単位とし、山田決裁）。
- 棄権判定・数値抽出はv2.0凍結のまま（判定規則の変更禁止）。非棄権・数値抽出不能は分母から除外し件数を独立報告。

- 山推定の相対閾値5%は変更しない。閾値感度（別値での山数の動き）は本測定の報告に感度分析として併記。
