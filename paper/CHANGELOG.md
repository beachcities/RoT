# 改訂履歴

この試論は現在進行形の文書です。主要な変更をここに記録します。

## 2026-08-21

- 第5節「測って分かったこと」を新設。実際に測って確かめられた範囲と、測れていないものを、仮説の節から分離した。既存の第5〜7節は第6〜8節に繰り下げ。第1〜4節と第6節以降の本文は変更していない。
- 冒頭の位置づけを改訂。「定量的実測を伴わない仮説を含む」から、どの節が仮説でどの節が実測かを示す形に変更。
- 第8節（旧第7節）の主権に関する主張に、モデル能力による効き方の差が現在の指標では読み取れていない旨の留保を追加。
- Call for Collaboration を現状に合わせて改訂。三つの仮説のうち、探索の削減については最初の実測を得た一方、CoT削減効果と交互作用効果は未検証または現在の測り方では答えられない状態であることを明記。

## 2026-08-20

- 指標名を Return **of** Token から Return **on** Token に変更。ROI（return on investment）と同型の効率指標であり、「投じたトークンに対して」を指す on が定義に即するため。略称 ROT は変更していない。
- ファイルを `paper/return-on-token.md` に改名（旧 `paper/return-of-token.md` は削除）。
- 英語版の下訳 `paper/return-on-token.en.md` を追加。日本語版と食い違う場合は日本語版が正。

## 2026-08-19

- 初版を公開。
- 用語の修正：L4層の打ち手について、`right-sizing` を「モデルの適正規模化」と訳出（当初の訳語は方向を示す語と誤読される恐れがあったため）。
- 【Call for Collaboration】から検証用リポジトリへのリンクを追加。

## 記録の方針
