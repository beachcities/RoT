## (c) 修正の内容

### 主解析の分母

`values` はもともと数値回答だけなのに、占有率の分母が `len(kept)`（非棄権**全件**）に
なっていた。**数値を取り出せなかった標本のぶんだけ、占有率が下振れする**。

```
修正前:  m = len(kept)          # 非棄権の全件
修正後:  m = len(answered)      # 非棄権かつ数値が取れた件数
        unparsed = len(kept) - len(answered)
```

取り出せなかった件数は**黙って分母から消さず**、`非棄権だが数値抽出不能` として
セル別出力に独立の項目で出す（集計表にも `不能` 列と `分母` 列を追加）。

### 感度分析側の分母

同じ原則で、数値分布の占有率の分母を **実際に数値が取れた `all_values` の件数**に
揃えた（`感度_棄権込み.数値が取れた` として件数も出す）。

### 変更していないもの

* **棄権率の分母は全標本**（`len(abstained) / n`）。
* **総トークンは全標本**。
* 山推定のアルゴリズム（相対閾値5%の隙間切り）、V/H/γ、master seed、完全交差、
  200標本設計、preflight 手順。

### `build_v4.py` のコメント差し替え（ロジック変更なし）

```
旧: スモークで固定側は 8/10 が同一の誤答へ集中し、特定変種の癖を測ってしまう
新: 固定すると、そのセルで観測できるのが1変種だけになり、変種効果を分離できない
    ——測った散らばりが課題の性質なのか、たまたま選んだ残候補集合の癖なのかを
    分けられない。振ったうえで variant×seed を二段で記録すれば、変種内と
    変種間の揺れを分解できる。
```

`8/10` の旧誤記は `build_v4.py` / `summarize_v4.py` / `v4_grid.py` のいずれにも
残っていないことを機械的に確認済み。

## (d) 追加した selftest の内容

`計器v2.0: 山統計の分母は非棄権かつ数値が取れた件数`

4標本で差を固定する——**正解1 / 誤答1 / 棄権1 / 非棄権だが数値が取り出せない1**。

| 検査項目 | 期待値 |
| --- | --- |
| `標本数` | 4 |
| `棄権数` / `棄権率` | 1 / 0.25（**分母は全標本**） |
| `非棄権数` | 3 |
| `非棄権だが数値抽出不能` | **1**（黙って消さない） |
| `数値が取れた` | 2 |
| `正解山の占有率` | **0.5**（分母は 2 であって 3 ではない） |
| `最大山の占有率` | 0.5 |
| `感度_棄権込み.数値が取れた` | 3 |
| `感度_棄権込み.正解山の占有率` | 1/3 |
| `総トークン` | 4（**全標本**） |

修正前の実装ならば `正解山の占有率` は 1/3 になる。この検査がその差を固定する。
